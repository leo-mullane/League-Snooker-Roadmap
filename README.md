# UK League Snooker — rebuild prototypes (V2, designed)

Clickable prototypes for a full rebuild of leaguesnooker.co.uk, prepared by ClerksWell following the
phase 1 review (15 October 2026). Five core templates plus a foundations page, 25 pages in all,
covering all 48 ideas from the review. The landing page lists where each idea is shown.

V2 applies the League Snooker design system, entirely in `src/css/theme.css`; delete that file (and
`src/js/photos.js`) to get the V1 greyscale wireframes back. Fonts are Big Shoulders Display and
Source Sans 3 from Google Fonts. The live site has almost no photography of its own: the championship
venue photo is hotlinked from leaguesnooker.co.uk by `src/js/photos.js` and applied only once it loads;
everything else shows a to-scale snooker table generated by `python3 tools/gen-tables.py`
(geometry from ClerksWell's Snooker & Pool Layout Board) into `src/assets/table-*.svg`. Photography © UK League Snooker. The
repository and Pages site are public.

## View
Live: https://hrhlescargotleo.github.io/League-Snooker-Roadmap/

Or open `docs/index.html` in a browser. No server or install needed.

GitHub Pages publishes from the `docs/` folder on `main`
(Settings → Pages → Deploy from a branch → `main` / `/docs`).

## Prototypes
1. Community home — `pages/home.html`, with `leagues.html` (finder), `championship.html`, `community.html`
2. League hub — `pages/league.html`, with `tables.html`, `fixtures.html`, `cups.html`, `clubs.html`, `club.html?club=<id>`, `archive.html`, `league-info.html`
3. Match centre — `pages/match.html?m=<id>`, `submit-result.html`, `live.html`
4. Players — `pages/player.html?p=<id>`, `players.html`, `breaks.html`, `account.html`
5. Run a league — `pages/run-a-league.html`, `setup.html`, `sign-in.html`, `admin.html`
+ Foundations — `pages/foundations.html` and `modules/library.html`

Requirements (R-numbers match the idea numbers): `requirements/requirements.md`.

## Data
`src/js/data.js` is generated by `python3 tools/gen-data.py`. League, team and club names, club
postcodes and Cambridge & District Division 1 results for weeks 1–3 are real (as published on
15 October 2026). Player names, all other results, breaks, careers, cups and archive winners are
invented sample data.

## Build
```
node build-includes.js && node validate.js
```
Edit files in `src/`; `docs/` is generated (commit it, as GitHub Pages serves it). The prototype
navigator (top bar with the Notes switch) and the previous/next footer live in `src/includes/`, as
do the league head and hub tabs. Shared behaviour is in `src/js/wireframe.js` (generic components)
and `src/js/league.js` (League Snooker pages).
